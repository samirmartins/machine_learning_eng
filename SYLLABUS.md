# Syllabus - Machine Learning Applied to Engineering

An undergraduate course in **Electrical Engineering**, offered at the **Federal University of São João del-Rei (UFSJ)**.

**Instructor:** Samir A. M. Martins

[Course materials](README.md)

## Objectives

- Apply machine learning techniques to engineering problems.
- Develop computational solutions for classification and regression tasks.
- Explore recommender systems and data analysis in applied contexts.
- Build reproducible experiments with widely used tools in the Python ecosystem.

## Course Content

### 1. Basic Python

- The Zen of Python
- Anaconda, libraries, and environments
- NumPy, Pandas, and Matplotlib

### 2. Statistics and Probability

- Measures of central tendency
- Correlation and causation
- Spurious correlations
- Dependence and independence
- Conditional probability
- Random variables and probability distributions

### 3. Data in Python

- File reading
- Retrieving data from reliable online sources
- Discovering and using APIs

### 4. Machine Learning

- Fundamental definitions
- Overfitting and underfitting
- The bias-variance trade-off

### 5. Classification Techniques

- K-nearest neighbors
- Logistic regression for classification
- Support vector machines
- Decision trees and random forests
- Using Scikit-learn for classification

### 6. Regression Techniques

- Simple and multiple linear regression
- Ridge regression
- LASSO
- Elastic Net
- Polynomial NARX models ([SysIdentPy](https://sysidentpy.org/) library for regression problems)
- Using Scikit-learn for regression

### 7. Recommender Systems

- Collaborative filtering
- Popularity baseline
- Precision@K

### 8. Applications to Real Systems

- Regression applied to F-16 fighter wing vibration using experimental accelerometer data
- Mathematical modeling of a motor-generator system using experimental data
- Benchmarks involving load prediction, commercial airline passenger forecasting, and recommender systems based on data

## Teaching Method

The course uses a theoretical and practical approach, combining:

- lectures;
- board work and conceptual discussions;
- computer laboratory sessions;
- implementation of models and analyses in Python.

## Development Environment

**Python** with **Conda** environment management is recommended.
